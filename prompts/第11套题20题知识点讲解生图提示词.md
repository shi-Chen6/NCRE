# 第 11 套题 · 20 题知识点讲解生图提示词（image2.5）

> 用途：把每一条「生图提示词」直接复制给 image2.5，即可生成一张面向零基础学生的**知识点讲解信息图**——学生看图就能明白这道题在考什么、正确答案为什么对、其他选项错在哪。
> 数据来源：`output/data/set_11.json`（题干与选项）、`output/answers/set_11.json`（答案与解析）。
> 出图顺序：每题一张，按 01 → 20 依次生成。

**本套语言规范（沿用第 3–10 套）**

1. **提示词正文一律用英文写**画面描述（风格、构图、元素、光影、比例都用英文表达）。
2. **凡是要出现在图上的文字，一律写成 `"中文"` 形式**（用英文双引号把简体中文包起来），例如 `a label reading "外部存储器"`。
3. **成图内的文字语言是简体中文**——图上只出现中文，不出现成句英文；允许保留的字母词仅限通用缩写与单位（CPU / RAM / ROM / bit / ASCII / GB / MB 这类）。
4. 文档里的「本题信息」「知识点讲解要点」「建议风格」等**讲解与元信息仍用中文**。
5. **正文里不要出现 `undefined` / `NaN` / `null` 这类词**，要表达"自定义/未指定"请用 `self-defined` / `custom`。

## 一、通用规则（先读这一节，20 条都适用）

1. **统一构图 = 四区信息图**：每张图切成四块——**A 区主场景**（左侧约 6 成宽，生活类比，图元最密）、**B 区原理图**（右上，技术结构或流程）、**C 区数据卡**（右下，数值／单位／正误对照）、**D 区结论条**（底部通栏，一句话结论＋正确答案）。保持"左看场景、右看原理、下看结论"的读图路线。
2. **风格按题走**：抽象结构题（CPU、字长、存储器、驱动器）用 **isometric / tech** 风；生活类题（仓库、厨房、公路、气象台）用 **flat illustration**；码值与换算题（二进制按权展开）用 **hand-drawn chalkboard**。
3. **比例统一 16:9**。
4. **"内容丰富"的落地方式**：丰富靠**画面元素**（人物、道具、箭头、剖面、图标、小徽章），单张图**图元 12～15 个**；图上文字一律 **最多 5 处、每处不超过 6 个字**（含数字与符号的整串也算一处），全部用 `"中文"` 形式写在英文提示词里。
5. **统一负面提示词**（20 条共用，附在提示词末尾）：
   - 英文版：`garbled text, duplicated text, watermark, logo, signature, dense small text, long English sentences, English words on the image, photorealistic faces, horror elements, overexposure, noise, cluttered layout, overlapping elements, distorted hands, multiple panels`
   - 中文版（若上游更认中文）：`乱码文字、文字重影、多余水印、logo、签名、密集小字、长句、图上出现成句英文、真人照片、恐怖元素、过曝、噪点、画面拥挤、元素重叠、扭曲的手、多版本拼贴`
6. **画面基调统一**：每张图内部底色一致（浅底配深字，深底配亮字）。
7. **中文渲染兜底**：若中文出现乱码或错字，先删掉次要标签、只留 2～3 处最关键的中文；仍不行时把该处 `"中文"` 换成同位置的英文备用标签再试。

### 【生图 05】第 5 题 · 二进制 111111 转十进制是 63

- **建议风格**：手绘板书，深墨绿黑板，白粉笔 + 黄色高亮，手写箭头与方框
- **建议比例**：16:9
- **画面结构**：A＝六个开关与砝码｜B＝按权展开算式｜C＝两个选项划叉｜D＝结论条

**本题信息**
- 题目：无符号二进制整数 111111 转换成十进制数是（ ）。
- 选项：A 71　B 65　C 63　D 62
- 正确答案：**C**
- 错因：按权展开 **1×32 + 1×16 + 1×8 + 1×4 + 1×2 + 1×1 = 63**。也可用口诀"**6 位全 1 就是 2⁶−1 = 63**"。A 的 71、B 的 65、D 的 62 都不是按权相加的结果。

**知识点讲解要点**：二进制每一位都带着**固定的重量**：右起第 1 位值 **1**，然后 **2、4、8、16、32** 依次翻倍。**是 1 就把这份重量留下，是 0 就丢掉**，最后全部加起来。六个 1 全在，就是 **32+16+8+4+2+1 = 63**。
