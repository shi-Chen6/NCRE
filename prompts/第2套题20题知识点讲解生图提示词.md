## 一、通用规则（先读这一节，20 条都适用）

1. **统一构图 = 四区信息图**：每张图都切成四个区域——**A 区主场景**（生活类比，占左约 6 成宽，图元最密）、**B 区原理图**（右上，技术结构或流程）、**C 区数据卡**（右下，算式 / 单位 / 数值对照）、**D 区结论条**（底部通栏，一句话结论 + 正确答案）。四区之间用细线或浅色底块区分，整体保持"左看场景、右看原理、下看结论"的读图路线。
2. **风格按题走，不搞一刀切**：抽象结构题（CPU、字长、磁道）用**等距微立体 / 科技感**；生活类题（收藏夹、乐高、邮局）用**扁平插画**；计算与进制题（点阵容量、显存、八进制）用**手绘板书**最有教学味。具体见每条「建议风格」。
3. **比例统一 16:9**，便于整页排进 PPT、讲义或刷题卡片；若做缩略图可改 1:1 并裁掉左右留白。
4. **"内容丰富"的落地方式**：丰富靠**画面元素**（人物、道具、箭头、剖面、图标、小徽章），单张图图元提到 **12～15 个**；**不靠文字堆砌**——图中文字一律控制在 **最多 5 处、每处不超过 6 个字**（每条提示词已用「」标出）。文字越多，中文越容易糊。
5. **统一负面提示词**（20 条共用，直接附在提示词末尾）：
   `乱码文字、文字重影、多余水印、logo、签名、密集小字、长句、真人照片、恐怖元素、过曝、噪点、画面拥挤、元素重叠、扭曲的手、多个版本拼贴`
6. **画面基调要统一**：每张图**内部底色保持一致**（要么浅底要么深底），不要一张图里半浅半深；浅底配深字，深底配亮字，保证学生看清。
7. **中文渲染兜底**：若某次出图里出现乱码或错字，把该处标签换成同位置给出的**英文备选**再试一次；或减少标签数量、只留最关键的 2～3 处。

### 【生图 01】第 1 题 · CPU 的组成 = 控制器 + 运算器

- **建议风格**：等距微立体 3D 芯片风，深灰蓝底，青绿与橙色发光线条，金属磨砂质感，柔和阴影
- **建议比例**：16:9
- **画面结构**：A＝双人协作工作间｜B＝芯片内部两区块剖视｜C＝内存与缓存划叉卡｜D＝结论条

**本题信息**
- 题目：构成 CPU 的主要部件是（ ）。
- 选项：A 内存和控制器　B 内存、控制器和运算器　C 高速缓存和运算器　D 控制器和运算器
- 正确答案：**D**
- 错因：内存和高速缓存都属于**存储器**，位于 CPU 之外；CPU 内部只有控制器和运算器两大部分。

**知识点讲解要点**：CPU 是一台"干活的小工厂"，里面只有两位角色——**运算器**负责算（加减乘除、比较大小），**控制器**负责管（取指令、发命令、掌握节拍）。内存和高速缓存虽然常和 CPU 一起出现，但它们是"仓库"，在 CPU 外面，不算 CPU 的组成。

**生图提示词（可直接复制）**

> 等距微立体 3D 风格科普信息图，横版四区构图，深灰蓝科技底色，青绿与橙色发光线条，磨砂金属质感，柔和阴影，整体干净不杂乱。A 区（左侧约六成宽）：一间简洁的等距微立体工作间，左边一位戴袖套的会计坐在矮桌前，桌上摆着算盘与写有加减乘除符号的账本，代表运算；右边一位穿着工作马甲的主管站在调度台后，一手拿对讲机、一手举着写满勾号的任务清单，代表指挥；两人之间有一根发光的协作箭头相连，地面散落几个写着 0 和 1 的小方块。B 区（右上）：一枚方形 CPU 芯片的剖视图，内部被分成左右两半并发光高亮——左半是一枚刻着加号减号乘号除号齿轮的运算模块，右半是一支指挥棒与节拍时钟图标构成的指挥模块，两块之间由一条发光总线相连。C 区（右下）：一张浅色小卡片，上面画着内存条与高速缓存两个方块，方块上覆一层暗色半透明遮罩并打一个叉，旁边一条短虚线连向 CPU 之外，表示它们不在 CPU 里。D 区（底部通栏）：一条深色圆角结论条，条内写一句结论并配一个绿色对勾徽章。全图仅出现四处简体中文短标签：「运算器」「控制器」「CPU」「不在 CPU 内」，白色或深色粗黑体，置于圆角小底衬上，每处不超过六个字。16:9 横版构图，高清，背景干净。

- **英文标签备选**：ALU / Control Unit / CPU / Outside CPU

### 【生图 02】第 2 题 · 电子计算机四代元件演进

### 【生图 03】第 3 题 · 网络按覆盖范围分三类

- **建议风格**：扁平网络拓扑插画，浅蓝白底，蓝色主色，绿色高亮正确项，线条简洁

- 题目：计算机网络分为局域网、城域网和广域网，下列属于局域网的是（ ）。

### 【生图 04】第 4 题 · 数据传输速率的度量单位

- **建议风格**：科技仪表盘风，深靛蓝底，青绿与琥珀色发光仪表，玻璃质感
- **建议比例**：16:9
- **画面结构**：A＝水管与流量计｜B＝Modem 数模转换｜C＝四个单位各归其位｜D＝结论条

**本题信息**
- 题目：调制解调器（Modem）的主要技术指标是数据传输速率，它的度量单位是（ ）。
- 选项：A MIPS　B Mbps　C dpi　D KB
- 正确答案：**B**
- 错因：MIPS 衡量计算机运算速度，dpi 是打印机与扫描仪的分辨率单位，KB 是存储容量单位；只有 bps（及 Mbps）表示每秒传输的比特数，即传输速率。

**知识点讲解要点**：**bps = 每秒传多少比特**，Mbps 就是每秒上百万比特，专门用来量"网速快不快"。其他三个单位各有各的东家：MIPS 管"算得多快"，dpi 管"印得多细"，KB 管"装得多少"。

**生图提示词（可直接复制）**

> 科技仪表盘风格信息图，横版四区构图，深靛蓝底色，青绿与琥珀色发光线条，玻璃与金属质感，轻微光晕。A 区（左侧约六成宽）：一根横贯画面的透明水管，管中流动着成串发光的小方块，管身中段装一枚圆形流量计，表盘指针指向高位，表盘外圈有一圈发光刻度；水管右侧变细，表示流速变化，管壁贴着几枚小巧的计量标记。B 区（右上）：一台居中放置的调制解调器设备，正面有电话线接口与网线接口，两侧各引出一条曲线——左侧是平滑的模拟波形，右侧是方正的数字方波，设备上方有一枚双向转换箭头徽章，表示"数字与模拟互相转换"。C 区（右下）：一张深色对照卡，卡内四行小图标各配一个短标签——一枚转速表图标、一台打印机图标、一块硬盘图标、一枚网速表图标，其中网速表那一行被青绿色高亮勾出。D 区（底部通栏）：一条深色圆角结论条，内配琥珀色对勾徽章。全图仅出现五处简体中文短标签：「Mbps」「传输速率」「MIPS」「dpi」「KB」，白色或浅青粗黑体，置于深色圆角底衬上，每处为字母或两三字。16:9 横版构图，高清，背景干净。

- **英文标签备选**：Mbps / Transfer Rate / MIPS / dpi / KB
- **负面提示词**：见通用规则第 5 条

- **建议比例**：16:9
- **画面结构**：A＝只能坐 8 人的车厢｜B＝8 格数码盘｜C＝四个数逐个检票｜D＝结论条

**本题信息**
- 题目：按照数的进位制概念，下列各个数中正确的八进制数是（ ）。
- 选项：A 1101　B 7081　C 1109　D B03A
- 正确答案：**A**
- 错因：八进制的数码只能是 **0～7**。B 项含数字 8，C 项含数字 9，D 项含字母 B、A，都不合法；只有 A 项每一位都在 0～7 范围内。

**知识点讲解要点**：几进制，就允许几位"数字"。十进制用 0～9，**八进制只用 0～7**。所以判断一个数是不是合法八进制数，只要看有没有出现 8、9 或字母——出现一个就不合法。
