# 第 8 套题 · 20 题知识点讲解生图提示词（image2.5）

> 用途：把每一条「生图提示词」直接复制给 image2.5，即可生成一张面向零基础学生的**知识点讲解信息图**——学生看图就能明白这道题在考什么、正确答案为什么对、其他选项错在哪。
> 数据来源：`output/data/set_08.json`（题干与选项）、`output/answers/set_08.json`（答案与解析）。
> 出图顺序：每题一张，按 01 → 20 依次生成。

**本套语言规范（沿用第 3–7 套）**

1. **提示词正文一律用英文写**画面描述（风格、构图、元素、光影、比例都用英文表达）。
2. **凡是要出现在图上的文字，一律写成 `"中文"` 形式**（用英文双引号把简体中文包起来），例如 `a label reading "分辨率"`。
3. **成图内的文字语言是简体中文**——图上只出现中文，不出现成句英文；允许保留的字母词仅限通用缩写与单位（CPU / Mbps / MB/s / MIPS / CAD / CIMS 这类）。
4. 文档里的「本题信息」「知识点讲解要点」「建议风格」等**讲解与元信息仍用中文**。
5. **正文里不要出现 `undefined` / `NaN` / `null` 这类词**（会与页面占位检查冲突），要表达"自定义/未指定"请用 `self-defined` / `custom`。

## 一、通用规则（先读这一节，20 条都适用）

1. **统一构图 = 四区信息图**：每张图切成四块——**A 区主场景**（左侧约 6 成宽，生活类比，图元最密）、**B 区原理图**（右上，技术结构或流程）、**C 区数据卡**（右下，数值／单位／正误对照）、**D 区结论条**（底部通栏，一句话结论＋正确答案）。保持"左看场景、右看原理、下看结论"的读图路线。
2. **风格按题走**：抽象结构题（内存、扇区、硬件组成）用 **isometric / tech** 风；生活类题（教室、舞台、影院、办公室）用 **flat illustration**；数制与码值题（进制比大小、二进制移位）用 **hand-drawn chalkboard**。
3. **比例统一 16:9**。
4. **"内容丰富"的落地方式**：丰富靠**画面元素**（人物、道具、箭头、剖面、图标、小徽章），单张图**图元 12～15 个**；图上文字一律 **最多 5 处、每处不超过 6 个字**，全部用 `"中文"` 形式写在英文提示词里。
5. **统一负面提示词**（20 条共用，附在提示词末尾）：
   - 英文版：`garbled text, duplicated text, watermark, logo, signature, dense small text, long English sentences, English words on the image, photorealistic faces, horror elements, overexposure, noise, cluttered layout, overlapping elements, distorted hands, multiple panels`
   - 中文版（若上游更认中文）：`乱码文字、文字重影、多余水印、logo、签名、密集小字、长句、图上出现成句英文、真人照片、恐怖元素、过曝、噪点、画面拥挤、元素重叠、扭曲的手、多版本拼贴`
6. **画面基调统一**：每张图内部底色一致（浅底配深字，深底配亮字）。
7. **中文渲染兜底**：若中文出现乱码或错字，先删掉次要标签、只留 2～3 处最关键的中文；仍不行时把该处 `"中文"` 换成同位置的英文备用标签再试。

### 【生图 01】第 1 题 · CPU 能直接交换信息的是内存储器

- **建议风格**：等距微立体 3D，深灰蓝底，金属台面与发光总线，青绿 + 琥珀
- **建议比例**：16:9
- **画面结构**：A＝同桌递纸条与外地邮寄｜B＝总线直达与经内存中转｜C＝三种外存划叉｜D＝结论条

**本题信息**
- 题目：能直接与 CPU 交换信息的存储器是（ ）。
- 选项：A 硬盘存储器　B CD-ROM　C 内存储器　D U 盘存储器
- 正确答案：**C**
- 错因：硬盘、CD-ROM、U 盘都是**外存**，属于外部设备，其中的信息**必须先调入内存**才能被 CPU 使用；只有**内存储器**通过地址总线与数据总线与 CPU 直接相连，能直接交换信息。

**知识点讲解要点**：把 CPU 和内存想成**同桌的两个人**——想传什么随手一递就到。硬盘、U 盘、光盘是"外地的朋友"，东西得先寄到同桌手里，CPU 才拿得到。所以能**直接**交换信息的只有**内存储器**。
